# Python Scripts Repository 🐍

A collection of useful Python scripts for various tasks - from file organization to music charts!

![Python Version](https://img.shields.io/badge/python-3.8%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## 📂 Repository Contents

### File Organizer
- Organizes your Downloads folder by file type
- Creates categorized folders (Images, Documents, etc.)
- Progress tracking and summary report

### Top 50 Songs Fetcher
- Fetches current top 50 songs from Billboard/Spotify
- Exports data to CSV/Excel
- Customizable date range
