# Downloads Organizer 📂

A Python script to automatically organize your Downloads folder by file type.

## Features
- Copies files to categorized folders
- Progress tracking
- File type categories (images, documents, etc.)

## How to Use
1. Install Python
2. Run:
   ```bash
   python organizer.py
   ```
3. Find organized files in `~/Organized_Downloads`

## Customization
Add file extensions in the `file_categories` dictionary
